# daemon 测试用例

## 组件按依赖顺序初始化

- **场景**：系统启动时，存在依赖关系的两个组件，被依赖组件就绪前，依赖它的组件不会被初始化；待被依赖组件就绪后，该组件才被初始化
- **来源**：需求 §F1
- **LLM 方式**：fake
- **阶梯级**：L0
- **状态**：待实现

## 外部入口仅在所有组件就绪后接收消息

- **场景**：系统启动过程中组件尚未全部就绪 → 此时通过外部入口（IM/CLI）发送消息 → 消息不被系统接收；启动完成所有组件就绪后 → 同一消息被系统接收并按对应入口处理
- **来源**：需求 §F1
- **LLM 方式**：fake
- **阶梯级**：L0
- **状态**：待实现
