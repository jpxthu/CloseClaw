# 进程与协议端点

## 概述

通过本地回环 HTTP 服务提供 OpenAI、Anthropic 对话端点与模型发现端点，以黑盒方式接入真实 CloseClaw 二进制。

## 架构

### 进程与运行生命周期

服务作为独立进程由测试者或测试运行器启动，仅绑定本机回环地址，拒绝非回环监听。支持由操作系统分配空闲端口并把实际监听地址提供给运行器。服务不依赖真实模型或外部网络，不进入发布构建，也不随产品分发。

运行器在本地控制面创建测试运行命名空间并装载场景，全部配置校验通过后才开始发被测请求；直接启动时同样需明确装载配置，不以解析失败或目录不存在为由降级为空引擎。多个运行可共用监听端点，但其声明、会话、发现序列和缓存均独立。控制面的创建、重置和释放由测试运行器调用，不是供模型选择的对话场景，不混入协议正文。

运行结束显式释放命名空间，或销毁独立服务进程。释放后对迟到请求返回运行已结束的错误，不自动重建命名空间，避免异步投递污染后续测试。状态规则见 [scenario-engine](scenario-engine.md)。

### 接入与会话关联

运行器把 [config](../config/README.md) 的模型供应商端点指向本服务，并显式启用 [LLM 本地测试关联](../llm/protocol-mapping.md#本地测试关联)。带外 HTTP 关联信息的唯一定义在该契约，本端点只解析运行命名空间与匿名会话键，不把它们写入消息、工具或缓存前缀。

同一监听端口可接收同一 Agent 的多个并发主/子 Session；端点不按消息、连接、模型 ID、API 凭据或到达顺序猜测会话。两种对话协议使用同一关联契约。缺少关联上下文时只允许场景引擎明确支持的无状态路径，有状态序列和缓存不得落入公共默认会话。凭据类错误由场景注入，供应商凭据不作为会话身份或控制面授权依据。

### 协议路由与职责

| 端点 | 协议 | 方法 | 职责 |
|------|------|------|------|
| `/v1/chat/completions` | OpenAI | POST | 完整 JSON 或 SSE 对话响应 |
| `/v1/messages` | Anthropic | POST | 完整 message 或 SSE 对话响应 |
| `/v1/models` | 模型发现 | GET | 运行命名空间内的模型列表或发现错误 |

端点地址由运行器按客户端对 base_url 与标准相对路径的拼接方式配置，不能重复或遗漏版本路径。协议层保留请求中的有序内容、System Prompt、工具和缓存标记，向引擎提供完整语义及协议身份；不只抽取可见文本。引擎使用协议身份匹配、校验能力和划分缓存，不处理 JSON/SSE 格式。

响应决策返回后由协议层编码原生 JSON、错误体与 SSE 事件，投递层只执行发送、分段等待与断流。对应机制见 [scenario-engine](scenario-engine.md)、[delivery](delivery.md)。

### 模型发现模拟

配置阶段的模型发现请求仅使用运行命名空间，不要求 Session 身份。场景控制面可声明模型列表（含已知或未知模型）、认证错误、限流、服务端错误及延迟造成的超时；列表和错误按运行器选定的独立发现序列返回，不改动对话状态。

已知模型发现用例使用被测知识库已收录的模型标识，未知模型用例显式选择未收录标识，不能用任意占位模型声称验证成功发现。发现序列的选择、缺失与耗尽规则见 [scenario-engine](scenario-engine.md)。被测方的发现、过滤和失败处置以 [llm 需求 F7](../../requirements/llm.md) 为准，设计入口为 [llm/model-discovery](../llm/model-discovery.md)，本服务不复制其重试或回退策略。

## 数据流

1. 启动回环服务，取得监听地址；运行器创建命名空间、装载场景并配置被测二进制的本地测试接入。
2. 收到请求，验证命名空间与带外关联，按标准端点解析协议正文。
3. 对话请求交付完整请求和匿名会话键；发现请求交付运行级发现控制流。
4. 引擎完成决策后，协议层编码响应，投递层执行发送。
5. 关联记录决策与投递结果；测试结束释放命名空间或关闭进程。

## 模块关系

- **模块外上游**：测试者与运行器配置并管理本地服务；真实 CloseClaw 二进制通过标准 HTTP 协议调用。
- **模块内下游**：[scenario-engine](scenario-engine.md) 生成决策，[delivery](delivery.md) 执行发送；协议层编码缓存模拟返回的用量，不直接驱动缓存组件。
- **跨模块**：[config](../config/README.md) 承载本地端点与关联配置；[LLM 本地测试关联](../llm/protocol-mapping.md#本地测试关联) 定义带外传输；[llm/model-discovery](../llm/model-discovery.md) 是被测发现链路入口。
