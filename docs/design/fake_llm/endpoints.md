# 进程与协议端点

## 概述

通过本地回环 HTTP 服务提供 OpenAI、Anthropic 对话端点、模型发现端点与本地控制面，以黑盒方式接入真实 CloseClaw 二进制。

## 架构

### 进程与运行生命周期

服务作为独立进程由测试者或测试运行器启动，仅绑定本机回环地址，拒绝非回环监听。支持由操作系统分配空闲端口并把实际监听地址提供给运行器。服务不依赖真实模型或外部网络，不进入发布构建，也不随产品分发。

一个进程可同时承载多个运行命名空间；每个命名空间对应一次测试运行，各有独立的场景集、会话、发现序列与缓存。命名空间标识由控制面生成，在进程生命周期内唯一且不复用，释放后不再创建。销毁进程终止其全部命名空间；释放命名空间只清除该次运行的状态。

本地控制面与对话、发现端点共用监听地址，通过独立路径前缀区分。控制面请求与响应是控制结构，不是协议正文，不进入协议解析或场景匹配，也不作为模型可选择的对话场景：

| 操作 | 作用 |
|------|------|
| 创建 | 新建运行命名空间并装载场景集与发现声明 |
| 重置 | 清空该命名空间的匿名会话、响应游标、逻辑时钟、缓存与发现游标，保留命名空间与已装载声明 |
| 释放 | 销毁该命名空间的全部状态，此后携带它的请求返回运行已结束错误 |

创建时校验全部配置，通过后才发布该次运行的就绪状态，失败不静默降级；运行器收到就绪后才开始发被测请求。重置由运行器在确认无在途请求时调用，重置后新请求从初始状态重新推进。释放后不自动重建命名空间；未装载任何命名空间的进程可以接受控制面请求，但对对话与发现请求返回运行未找到错误。

### 接入与会话关联

运行器把 [config](../config/README.md) 的模型供应商端点指向本服务，并把运行命名空间写入接入配置，显式启用 [LLM 本地测试关联](../llm/protocol-mapping.md#本地测试关联)。带外 HTTP 关联信息的唯一定义在该契约；本端点解析运行命名空间与匿名会话键，不把它们写入消息、工具或缓存前缀。

运行命名空间是所有请求的前置条件；匿名会话键只用于有状态对话。单会话、无状态响应用例可只携带命名空间；多步序列、缓存与并发隔离必须提供会话键，缺失时按 [场景引擎](scenario-engine.md) 的无状态规则处理，不得落入公共默认会话。模型发现请求只携带命名空间。

同一监听端口可接收多个并发主/子 Session，可来自不同 Agent；端点不按消息、连接、模型 ID、API 凭据或到达顺序猜测会话。两种对话协议使用同一关联契约。凭据类错误由场景注入，供应商凭据不作为会话身份或控制面授权依据。

### 协议路由与职责

| 端点 | 协议 | 方法 | 职责 |
|------|------|------|------|
| 控制面路径（独立前缀） | 控制面 | 创建/重置/释放 | 运行命名空间生命周期与场景装载，不参与协议解析 |
| `/v1/chat/completions` | OpenAI | POST | 完整 JSON 或 SSE 对话响应 |
| `/v1/messages` | Anthropic | POST | 完整 message 或 SSE 对话响应 |
| `/v1/models` | 按发现声明 | GET | 运行命名空间内的模型列表或发现错误 |

对话端点的协议由路径确定。模型发现路径在两种协议下相同，请求正文与关联信息都不携带协议身份，因此发现声明自带协议且每个命名空间至多一份，端点按声明的协议编码列表与错误体；未声明发现序列时返回场景执行错误。

端点地址由运行器按客户端对 base_url 与标准相对路径的拼接方式配置，不能重复或遗漏版本路径。协议层保留请求中的有序内容、System Prompt、工具和缓存标记，按请求开关决定是否编码用量（如 OpenAI 流式用量开关），向引擎提供完整语义及协议身份；不只抽取可见文本。引擎使用协议身份匹配、校验能力和划分缓存，不处理 JSON/SSE 格式。

响应决策返回后由协议层编码原生 JSON、错误体与 SSE 事件；投递层执行发送、错误与延迟注入、断流。对应机制见 [scenario-engine](scenario-engine.md)、[delivery](delivery.md)。

### 模型发现模拟

配置阶段的模型发现请求仅使用运行命名空间，不要求会话身份。控制面选定一份发现声明并声明其协议，声明可包含模型列表（含已知与未知模型）、模型 ID、显示名与所有者字段，以及认证失败、权限不足、限流、服务端错误、超时等错误；每个命名空间至多一份，多份在加载期拒绝。

未声明的显示名或所有者字段按该协议标准最小字段返回：需要验证被测方的派生分支时不声明显示名，验证直接使用分支时显式声明。错误注入区分认证失败、权限不足与瞬态错误（限流、服务端错误、超时）；超时可由声明延迟造成，也可直接返回 504 响应。

已知模型发现用例使用被测知识库已收录的模型标识，未知模型用例显式选择未收录标识，不能用任意占位模型声称验证成功发现。发现序列的选择、缺失与耗尽规则见 [scenario-engine](scenario-engine.md)。被测方的发现、过滤和失败处置以 [llm 需求 F7](../../requirements/llm.md) 为准，设计入口为 [llm/model-discovery](../llm/model-discovery.md)，本服务不复制其重试或回退策略。

## 数据流

1. 启动回环服务，取得监听地址；运行器经控制面创建命名空间、装载场景与发现声明，取得就绪状态。
2. 运行器把命名空间写入被测侧接入配置并启用本地测试关联，然后开始发被测请求。
3. 对话请求到达端点：先校验命名空间与关联信息，再按路径解析协议正文，交付完整请求与匿名会话键。
4. 发现请求只校验命名空间，交付命名空间声明的独立发现序列，不进入对话匹配或缓存。
5. 引擎完成决策后，协议层编码响应与错误体，投递层执行发送、延迟与断流。
6. 决策与投递结果关联记录；运行结束由控制面释放命名空间或销毁进程。

请求失败分三类：命名空间不存在或已释放为运行错误；协议正文或关联信息无法解析、协议语义非法为请求错误；零命中且无兜底、关联不满足场景要求、用量约束不成立或序列耗尽为场景执行错误。三类都不修改状态、不终止其他会话，也不返回隐式默认响应；完整分类见 [scenario-engine](scenario-engine.md)。

## 模块关系

- **模块外上游**：测试者与运行器经控制面管理本地服务；真实 CloseClaw 二进制通过标准 HTTP 协议调用；接入与关联配置由 [config](../config/README.md) 承载、被测侧读取。
- **模块内下游**：[scenario-engine](scenario-engine.md) 生成决策，[delivery](delivery.md) 执行发送；缓存模拟把用量返回引擎，由引擎合成响应后交协议层编码，协议层不直接驱动缓存组件。
- **跨模块**：[config](../config/README.md) 承载本地端点与关联配置；[LLM 本地测试关联](../llm/protocol-mapping.md#本地测试关联) 定义带外传输；[llm/model-discovery](../llm/model-discovery.md) 是被测发现链路入口。
