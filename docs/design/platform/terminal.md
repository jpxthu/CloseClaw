# 终端能力检测

## 概述

终端能力检测接口检测当前终端的 ANSI 能力标记与终端可用宽度，供 CLI Chat 决定渲染模式与输出宽度。Linux、macOS 与 Windows（经 WSL2）的接口语义一致，原生 Windows 不支持。

## 架构

接口在一次调用内采集并返回 ANSI 能力标记与终端可用宽度两项平台原语：

- **ANSI 能力标记**：`TERM` 未设置、为空或为 `dumb` → 不支持；其余值 → 支持。标准输出不是终端（重定向到管道或文件）时同样按不支持处理，避免转义序列落入日志。该判定为启发式，以主流 ANSI 终端为基线；明确不支持 ANSI 的终端可用 `TERM=dumb` 声明。不支持时由终端渲染器降级为纯文本渲染。
- **终端可用宽度**：通过操作系统终端尺寸接口获取当前可用列数；获取失败或返回无效值（0 或负值）时回退默认宽度（80 列）。
- **调用时机**：批式与流式渲染均由 CLI Chat 的 TerminalPlugin 在渲染会话开始前调用一次，流式会话内复用同一结果；接口不缓存，窗口宽度变化在下次渲染会话生效。

## 数据流

1. 每次渲染会话开始前，上层（CLI Chat）调用终端能力检测接口
2. 接口在一次调用内采集 ANSI 能力标记：读取 `TERM` 并按匹配规则判定
3. 同一次调用内采集可用宽度：查询终端尺寸，失败或无效值回退默认 80 列
4. 返回 ANSI 能力标记与可用宽度两项结果
5. CLI Chat 将两项结果作为渲染入参交给终端渲染器，决定渲染模式与输出宽度

## 模块关系

- **上游**：CLI Chat（调用本接口，将两项结果交给终端渲染器决定渲染模式与输出宽度）
- **下游**：操作系统环境变量与终端尺寸 API（本接口调用）
- **无关**：Gateway、IM Adapter（不调用本接口，也不消费检测结果）
- **与模块内其他子功能**：与进程生命周期管理、配置目录、文件路径处理、临时目录并列，互不依赖
