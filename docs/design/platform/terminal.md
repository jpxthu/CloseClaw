# 终端能力检测

## 概述

终端能力检测接口检测当前终端的 ANSI 渲染能力与可用宽度，供终端渲染器决定渲染模式与布局约束。该检测在终端交互时调用。

## 架构

接口一次性返回两项结果，终端渲染器消费两者：

- **ANSI 能力标记**：`TERM` 环境变量含 `xterm`、`screen`、`ansi`、`vt100` 或 `color` → 支持 ANSI；其余 → 不支持（上层降级为纯文本输出，不出现乱码或转义序列原样显示）
- **终端可用宽度**：通过操作系统终端尺寸接口获取当前可用列数；获取失败时回退默认宽度（80 列）

判定覆盖主流终端环境：常见 Linux、macOS 与 WSL2 终端默认提供含 `xterm` 的 `TERM` 值，判定支持 ANSI。

## 数据流

1. 上层（如 CLI Chat 的终端渲染器）调用终端能力检测接口
2. 读取 `TERM` 判定 ANSI 能力；查询终端尺寸获得可用宽度（失败回退默认 80 列）
3. 返回能力标记 + 可用宽度

## 模块关系

- **上游**：CLI Chat（终端渲染器消费检测结果，确定渲染模式与布局约束）
- **下游**：操作系统环境变量与终端尺寸 API
- **与模块内其他子功能**：与进程生命周期管理、配置目录、文件路径处理并列，互不依赖
- **无关**：Gateway（不参与消息路由）、IM Adapter 各平台实现（非终端渠道不进行终端能力检测）
