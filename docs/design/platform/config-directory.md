# 配置目录

## 概述

配置目录接口提供 CloseClaw 的配置目录，供上层定位其中的配置数据。各受支持平台路径规则一致，上层无需处理平台差异。

## 架构

接口返回配置目录的绝对路径：Linux、macOS 与 Windows（经 WSL2）均为 `~/.closeclaw`。目录不存在时由本接口负责创建，确保首次启动无需手工建目录。

## 数据流

1. 上层（config 模块、Daemon）调用配置目录接口
2. 经 HOME 环境变量解析 `~` 为用户 home 目录，得到配置目录的绝对路径
3. 目录不存在则创建
4. 返回配置目录的绝对路径

## 模块关系

- **上游**：config 模块（经本接口获取配置目录，负责其下 `config/`、`agents/` 等子目录的布局与读写）、Daemon（启动初始化时经本接口确定配置目录）
- **下游**：操作系统文件系统与环境变量 API（本接口调用）；此外，配置数据经 config 模块供 CLI（Admin config 命令）、Gateway、IM Adapter 间接消费（数据消费方，不直接调用本接口）
- **与模块内其他子功能**：与进程生命周期管理、终端能力检测、文件路径处理并列，互不依赖；文件路径处理负责上层传入路径的通用展开与规范化，本接口只解析并返回自身固定的配置目录路径（`~` 解析为本接口内部逻辑，不复用文件路径处理接口）
