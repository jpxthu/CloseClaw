# 配置目录

## 概述

配置目录接口提供 CloseClaw 的配置根目录，供上层定位与读写配置。接口屏蔽平台差异，上层不感知操作系统。

## 架构

接口返回配置根目录的绝对路径：Linux、macOS 与 Windows（经 WSL2）均为 `~/.closeclaw`（`~` 展开为 home 目录）。目录不存在时由本接口负责创建，确保首次启动无需手工建目录。各受支持平台返回相同的路径表示，上层不感知平台分隔符差异。

## 数据流

1. 上层（CLI Admin 的 config 命令、Daemon 启动初始化配置）调用配置目录接口
2. 解析配置根目录 `~/.closeclaw`，按 HOME 环境变量展开为绝对路径
3. 目录不存在则创建
4. 返回配置根目录的绝对路径

## 模块关系

- **上游**：CLI Admin（config 命令读写配置）、Daemon（启动时初始化配置，经本接口确定配置根目录）
- **下游**：操作系统文件系统与环境变量 API
- **与模块内其他子功能**：与进程生命周期管理、终端能力检测、文件路径处理并列，互不依赖
- **无关**：Gateway、IM Adapter（不涉及配置目录）
