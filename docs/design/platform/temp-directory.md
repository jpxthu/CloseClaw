# 临时目录

## 概述

临时目录接口提供 CloseClaw 存放临时产物的系统临时目录的绝对路径，供后台任务输出、超长命令输出等场景取用。各平台按操作系统惯例解析，上层无需感知平台分支，也不硬编码 `/tmp` 等具体路径（见 [requirements/platform.md §F6](../../requirements/platform.md)）。

## 架构

接口返回系统临时目录的绝对路径，按平台解析：

| 平台 | 取值 |
|------|------|
| Linux / WSL2 | `$TMPDIR`；未设置或为空时回退系统默认 `/tmp` |
| macOS | `$TMPDIR`（launchd 为每个用户会话注入的每用户私有目录）；缺失属非标准会话环境，返回错误 |
| Windows | 不做原生适配，原生 Windows 不在支持范围；经 WSL2 时行为等同 Linux |

- **统一承接**：系统临时目录按平台规则解析，由本接口集中提供，上层（如 tools）直接取用，不再各自硬编码 `/tmp` 或判断平台。
- **不硬编码路径**：路径由运行环境决定，上层只消费接口返回的结果，不写死 `/tmp`、仓库目录等具体路径。
- **解析规则**：Linux / WSL2 读取 `$TMPDIR`，未设置或为空时回退 `/tmp`；macOS 取 launchd 注入的 `$TMPDIR`，缺失时返回错误。
- **只返回路径**：接口不负责创建、清理或预检可写性。Linux / WSL2 的 `/tmp` 由操作系统保证存在，macOS 正常会话由 launchd 注入；可写性与临时文件生命周期由使用方负责。
- **不保证持久**：临时目录内容不保证跨系统重启或系统清理周期留存，具体清理策略由操作系统与运行环境决定。
- **返回值规范化**：返回绝对路径，以 `/` 分隔且不含末尾分隔符（根路径除外），可直接用于路径拼接。
- **调用时机**：每次需要时调用，接口不缓存。

## 数据流

1. 上层模块（如 tools）请求系统临时目录
2. 按平台解析：
   - Linux / WSL2：读取 `$TMPDIR`；未设置或为空时回退 `/tmp`
   - macOS：读取 launchd 注入的 `$TMPDIR`；缺失时返回错误
3. 返回系统临时目录的绝对路径给上层

## 模块关系

- **上游**：tools（经本接口获取临时目录，后台任务输出文件、超长命令输出文件在本接口返回的目录下按 session 子目录落盘；session 隔离由 tools 负责，见 [background-tasks.md](../tools/background-tasks.md) 输出管理、[bash-tool.md](../tools/bash-tool.md) 输出持久化）
- **下游**：操作系统环境变量 API 与系统临时目录惯例（本接口调用）
- **无关**：Gateway、IM Adapter（不调用本接口，也不消费其返回值）
- **与模块内其他子功能**：与进程生命周期管理、配置目录、终端能力检测、文件路径处理并列，互不依赖
