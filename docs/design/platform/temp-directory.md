# 临时目录

## 概述

临时目录接口提供 CloseClaw 存放临时产物的系统临时目录的绝对路径，供后台任务输出、超长命令输出等场景取用。各平台按操作系统惯例解析，上层无需感知平台分支，也不硬编码 `/tmp` 等具体路径（见 [requirements/platform.md §F6](../../requirements/platform.md)）。

## 架构

接口返回系统临时目录的绝对路径，按平台解析：

| 平台 | 取值 |
|------|------|
| Linux / WSL2 | `$TMPDIR`；未设置、为空或不是绝对路径时回退系统默认 `/tmp` |
| macOS | `$TMPDIR`（launchd 为每个用户会话注入的每用户私有目录）；缺失或为空属非标准会话环境，返回错误 |
| Windows | 不做原生 Windows 适配，原生 Windows 不在支持范围；经 WSL2 时行为等同 Linux |

- **统一承接**：系统临时目录按平台规则解析，由本接口集中提供，上层（如 tools）直接取用，不再各自硬编码 `/tmp` 或判断平台。
- **不硬编码路径**：路径由运行环境决定，上层只消费接口返回的结果，不写死 `/tmp`、仓库目录等具体路径。
- **解析规则**：Linux / WSL2 读取 `$TMPDIR`，未设置、为空或不是绝对路径时回退 `/tmp`；macOS 取 launchd 注入的 `$TMPDIR`，缺失、为空或不是绝对路径时返回错误。
- **只返回路径或错误**：接口负责按平台规则解析并返回系统临时目录路径，不负责创建、清理、预检可写性，也不校验目录是否存在；解析失败（如 macOS 缺失 `$TMPDIR`）时返回错误，由使用方处理。Linux / WSL2 的 `/tmp` 由操作系统保证存在，macOS 正常会话由 launchd 注入；可写性与临时文件生命周期由使用方负责。
- **不保证持久**：临时目录内容不保证跨系统重启或系统清理周期留存，具体清理策略由操作系统与运行环境决定。
- **返回值规范化**：成功时返回绝对路径并去掉末尾分隔符（根路径除外）；解析结果为空或不是绝对路径时按缺失处理（Linux / WSL2 回退 `/tmp`，macOS 返回错误），不做相对路径到绝对路径的转换。
- **调用时机**：每次需要时调用，接口不缓存。

## 数据流

1. 上层模块（如 tools）请求系统临时目录
2. 按平台解析：
   - Linux / WSL2：读取 `$TMPDIR`；未设置、为空或非绝对路径时回退 `/tmp`
   - macOS：读取 launchd 注入的 `$TMPDIR`；缺失、为空或非绝对路径时返回错误
3. 归一化返回值（去掉末尾分隔符，根路径除外）
4. 返回系统临时目录的绝对路径给上层；解析失败时返回错误

## 模块关系

- **上游**：tools（经本接口获取系统临时目录，用于后台任务输出、超长命令输出等临时产物；具体存放布局、session 隔离与清理由 tools 负责，见 [background-tasks.md](../tools/background-tasks.md) 输出管理、[bash-tool.md](../tools/bash-tool.md) 输出持久化）
- **下游**：操作系统环境变量 API 与系统临时目录惯例（本接口调用）
- **无关**：Gateway、IM Adapter（不调用本接口，也不消费其返回值）
- **与模块内其他子功能**：与进程生命周期管理、配置目录、终端能力检测、文件路径处理并列，互不依赖。本接口只按平台惯例读取 `$TMPDIR`，不对结果做 `~` 与环境变量展开、也不做分隔符归一化，不经文件路径处理接口转换。
