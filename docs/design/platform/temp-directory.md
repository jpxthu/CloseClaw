# 临时目录

## 概述

临时目录接口提供 CloseClaw 存放临时产物的系统临时目录的绝对路径，供后台任务输出、超长命令输出等场景取用。各平台按操作系统惯例解析，上层无需感知平台分支，不硬编码 `/tmp` 等具体路径（见 [requirements/platform.md §F6](../../requirements/platform.md)）。接口无入参，只返回路径或解析失败结果。

## 架构

| 平台 | 取值 |
|------|------|
| Linux / WSL2 | `$TMPDIR`；未设置、为空或不是绝对路径时回退系统默认 `/tmp` |
| macOS | `$TMPDIR`（launchd 为每个用户会话注入的每用户私有目录）；缺失、为空或不是绝对路径时返回错误 |

原生 Windows 不做适配、不在支持范围；经 WSL2 时行为等同 Linux。

- **缺失口径**：`$TMPDIR` 未设置、为空或不是绝对路径统一视为「缺失」，按上表分别回退或返回错误。
- **统一承接**：系统临时目录按平台规则解析，由本接口集中提供，上层（如 tools）直接取用，不各自硬编码 `/tmp` 或判断平台。Linux / WSL2 回退值 `/tmp` 是本接口内唯一的固定路径，取值为平台默认而非上层硬编码。
- **只解析不落盘**：接口不创建、不清理、不预检可写性，也不校验目录是否存在；路径存在性与可写性由使用方在落盘时处理，落盘失败按使用方的写失败语义呈现。回退值 `/tmp` 由操作系统保证存在，macOS 正常会话由 launchd 注入。
- **取用规则**：`$TMPDIR` 的值按字面使用，不展开其中的 `~` 或 `$` 形态；返回路径以 `/` 分隔（受支持平台均以 `/` 为分隔符），不经[文件路径处理](file-path.md)接口转换。
- **结果态**：返回绝对路径，或「临时目录无法解析」这一种错误（macOS 缺失 `$TMPDIR`）；解析结果为空或不是绝对路径时按缺失处理，不做相对路径到绝对路径的转换。
- **返回值形态**：成功时返回绝对路径并去掉末尾分隔符（根路径除外）。
- **宿主归属**：返回的是宿主侧路径；沙盒执行环境下的路径可见性由 [permission 沙盒引擎](../permission/sandbox.md)与使用方的落盘、读取路径负责。
- **生命周期**：临时目录自身的内容留存不保证跨系统重启或系统清理周期，具体策略由操作系统与运行环境决定；本模块不负责清理。使用方在其作用域内的回收（如 [tools 后台任务](../tools/background-tasks.md) 输出随 Session 销毁回收）由使用方负责。
- **调用时机**：每次需要时调用，接口不缓存。

## 数据流

1. 上层模块（如 tools）调用本接口（无入参）
2. 按平台解析：
   - Linux / WSL2：读取 `$TMPDIR`；未设置、为空或非绝对路径时回退 `/tmp`
   - macOS：读取 launchd 注入的 `$TMPDIR`；缺失、为空或非绝对路径时返回错误
3. 去掉末尾分隔符（根路径除外），得到规范化的绝对路径
4. 返回系统临时目录的绝对路径给上层；解析失败时返回「临时目录无法解析」错误

## 模块关系

- **上游**：tools（经本接口获取系统临时目录，用于后台任务输出、超长命令输出等临时产物；输出文件的存放布局、按 Session 隔离的子目录创建与随 Session 销毁的回收由 tools 负责，见 [background-tasks.md](../tools/background-tasks.md) 输出管理、[bash-tool.md](../tools/bash-tool.md) 输出持久化）
- **下游**：操作系统环境变量 API 与系统临时目录惯例（本接口调用）
- **无关**：Gateway、IM Adapter（不调用本接口，也不消费其返回值）
- **与模块内其他子功能**：与进程生命周期管理、配置目录、终端能力检测、文件路径处理并列，互不依赖。本接口只按平台惯例读取 `$TMPDIR`，只做末尾分隔符去除，不做其它路径段归一化、不做 `~` 展开，也不经文件路径处理接口转换。
