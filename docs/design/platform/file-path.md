# 文件路径处理

## 概述

文件路径处理接口把上层传入的原始路径展开为统一的平台无关表示（展开 `~`、环境变量等简写），使上层使用统一的路径形式，不感知各操作系统的路径习惯。接口只做路径表示转换，不直接执行文件系统 I/O。

## 架构

- **简写展开**：home 简写（`~`）与环境变量由本接口展开，上层传入原始路径
- **统一表示**：展开后的路径统一使用 `/` 分隔符；受支持平台（Linux、macOS、WSL2）路径格式一致，无需平台分支
- **纯转换**：接口只做路径表示转换并返回结果，不直接读写文件系统

## 数据流

1. 上层传入原始路径（可能含 `~` 等简写）
2. 展开 home 简写与环境变量
3. 统一为 `/` 分隔符的内部表示
4. 返回平台无关的路径表示给上层

## 模块关系

- **上游**：需要平台无关路径处理的上层模块（如 CLI Admin 处理用户传入的路径参数）
- **下游**：操作系统环境变量 API
- **与模块内其他子功能**：与进程生命周期管理、配置目录、终端能力检测并列，互不依赖
- **无关**：Gateway、IM Adapter（不涉及文件路径解析）
