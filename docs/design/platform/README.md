# Platform

## 概述

- 关联需求文档：[requirements/platform.md](../../requirements/platform.md)
- 一句话：Platform 是操作系统抽象层，将进程生命周期管理、配置目录、终端能力检测、文件路径处理、临时目录五类操作系统相关操作封装为平台无关的接口，使上层模块不感知操作系统差异。

## 架构

Platform 按操作系统能力维度划分为五个能力接口，每个接口对应一类操作系统能力。上层模块以同一套接口调用；平台差异只体现为各接口约定的取值与失败条件（见 §平台实现边界），不改变调用方式。

Platform 的抽象范围限于进程生命周期、配置目录、终端能力、文件路径与临时目录五类操作系统能力。沙盒/隔离执行的平台机制选择不属本模块抽象范围，由 [permission 沙盒引擎](../permission/sandbox.md)自行实现。

### 子功能索引

| 文档 | 内容 |
|------|------|
| [进程生命周期管理](process.md) | PID 自注册、存活检测、终止请求、PID 清理与关闭信号订阅 |
| [配置目录](config-directory.md) | 返回配置根目录，根目录缺失时创建 |
| [终端能力检测](terminal.md) | 检测 ANSI 能力标记与终端可用宽度（宽度可为不可得） |
| [文件路径处理](file-path.md) | 展开路径简写与环境变量并统一为平台无关表示 |
| [临时目录](temp-directory.md) | 返回系统临时目录路径 |

### 平台实现边界

- **Linux**：原生支持
- **macOS**：进程信号、文件路径、终端能力检测、配置目录的接口语义均与 Linux 一致；临时目录取 launchd 注入的 `$TMPDIR`，缺失、为空或非绝对路径时返回错误（与 Linux 回退 `/tmp` 不同，见 [临时目录](temp-directory.md)）
- **Windows**：经 WSL2 覆盖，行为等同 Linux，不做原生 Windows 适配

各接口的平台差异另有子文档级界定（如临时目录的取值差异见 [临时目录](temp-directory.md)）。

## 数据流

1. 上层模块调用 platform 接口（平台无关）
2. 接口层经操作系统 API 完成实际操作，平台差异按各接口的解析规则处理（见 §平台实现边界）
3. 返回平台无关的结果给上层模块

按能力的关键分支（各接口的完整规则见对应子文档）：

- 进程生命周期：PID 自注册、存活检测（含残留 PID 文件清除）、终止（SIGTERM → 等待退出 → PID 清理兜底，无实例按成功返回）与关闭信号分发
- 配置目录：根目录不存在则创建根目录，创建失败返回错误
- 文件路径：展开 `~` 与环境变量，统一 `/` 分隔并归一化，解析失败返回错误
- 终端能力：判定 ANSI 能力标记并给出可用宽度，宽度不可得时不填充默认宽度
- 临时目录：按平台解析系统临时目录，解析失败返回错误

被动信号路径（不属请求-响应）：操作系统向 daemon 送达 SIGTERM / SIGINT → 接口分发至订阅的 daemon 关闭流程 → daemon 判定优雅 / 强制关闭并完成关闭，最后调用 PID 清理（见 [进程生命周期管理](process.md)）

## 模块关系

> 「上游/下游」指数据流与调用关系，不等于 crate 依赖；crate 依赖以 [STANDARDS.md 依赖方向允许边表](../STANDARDS.md) 为准。

- **上游**：CLI 模块（Chat 层与 Admin 命令输出的终端能力检测，在具备用户终端的 CLI 进程内调用；Admin 层的进程管理）、Daemon（启动关闭时的进程与信号处理、配置目录初始化）、config 模块（经配置目录接口定位配置目录并布局其下子目录，见 [配置目录](config-directory.md)）、tools 模块（后台任务输出与超长命令输出经临时目录接口落盘，见 [临时目录](temp-directory.md)；文件路径参数经 [文件路径处理](file-path.md) 展开 `~`）、slash 模块（Owner 传入路径的展开，见 [文件路径处理](file-path.md)）
- **下游**：操作系统 API（进程与信号、文件系统与配置目录惯例、终端尺寸，以及 home 解析用的环境变量与用户信息）——platform 调用操作系统完成实际操作
- **无关**：IM Adapter——不调用本模块接口，也不消费本模块产出；Gateway 经 terminal 渠道插件调度间接涉及终端能力检测，但不直接调用本模块接口。各子接口的无关界定见对应子文档
- **共享类型**：无——platform 收发的为操作系统原语及其结果（路径字符串、进程标识、终端能力标记与宽度等），不与业务模块共享 [common](../common/README.md) 中定义的数据结构
