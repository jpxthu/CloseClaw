# Fake LLM Server 需求

## 概述

Owner 可以在不依赖真实模型、算力和外部网络的环境中，用本地可完全受控的假 LLM 服务对 CloseClaw 的完整 LLM 调用链路进行确定性、可复现的端到端测试。

## 功能需求

### F1. 独立进程与黑盒接入

Owner 可以把 Fake LLM Server 作为独立进程在本地启动并监听本地端口，通过配置把 CloseClaw 的模型端点指向该本地地址，从而对编译后的真实二进制进行黑盒端到端测试。

Fake LLM Server 是开发与测试工具，不进入发布构建。

### F2. 协议与供应商模拟

Fake LLM Server 同时讲 OpenAI 与 Anthropic 两种标准对话协议，并可模拟多家供应商（MiniMax、GLM、DeepSeek、火山方舟、MiMo）的端点。

各供应商的特有行为——端点路径、推理/思考的开关与档位行为、错误返回形态、缓存字段命名——可分别模拟，使测试者能针对特定供应商验证 CloseClaw 的适配逻辑。

### F3. 场景驱动与确定性

测试者通过场景文件声明「给定请求特征 → 返回什么响应」。场景可覆盖文本回复、推理/思考、工具调用、流式输出、错误、延迟、token 用量，并支持多轮对话中逐轮给出不同响应。

同一场景下同一输入产出同一输出，测试可重复执行、结果稳定，不依赖时序或随机性。

场景格式与集成测试共用同一套定义，测试者编写的场景可在集成测试与黑盒端到端测试之间复用。

### F4. 流式输出模拟

Fake LLM Server 能以流式方式逐段输出响应，测试者可控制分段粒度与段间间隔，用于验证 CloseClaw 的流式解析、实时展示与中断处理。

两种协议的流式事件序列均被完整模拟，使 CloseClaw 的协议差异屏蔽逻辑可被验证。

### F5. 错误与重试注入

测试者可注入各类错误：HTTP 错误（如认证失败、限流、超时、服务端错误）、流式输出中途中断，以及 MiniMax 特有的「HTTP 返回成功但响应体内携带业务错误码」形态。

错误可触发 CloseClaw 的重试与回退行为（如限流的退避重试），用于验证重试与回退逻辑。

测试者也可注入延迟（首 token 延迟、逐段延迟、整体延迟），用于验证超时与回退路径（如模型发现超时）。

### F6. Token 用量模拟

Fake LLM Server 可在每次响应中返回完整的 token 用量信息——输入、输出、推理消耗、缓存命中、缓存写入——并可按场景配置，且支持在多轮对话中逐轮变化。

用量字段可缺失（模拟不返回缓存字段的供应商），CloseClaw 对应字段应显示为 0。

### F7. KV Cache 前缀缓存模拟

Fake LLM Server 能模拟前缀缓存的完整生命周期：首次请求写入缓存、后续请求命中缓存、缓存断开（命中量骤降）、缓存过期。

测试者可配置每轮响应返回的缓存命中/写入 token 数，从而驱动 CloseClaw 的缓存命中率统计、命中率下降告警、以及缓存断点检测。

这是测试 KV cache 相关行为（前缀稳定性、命中率、断点检测）的核心能力，是 Fake LLM Server 重点覆盖的范围。

### F8. 推理/思考模拟

Fake LLM Server 能模拟模型的推理/思考输出，并按供应商模拟其行为差异——如某些供应商的推理无法关闭、某些供应商在特定条件下才输出推理、某些供应商强制回传推理内容。

测试者可控制推理强度档位，验证 CloseClaw 的档位映射与降级逻辑。

### F9. 工具调用模拟

Fake LLM Server 能模拟模型发出工具调用请求，含流式分片、多轮工具调用回传、并行工具调用，用于验证 CloseClaw 的工具调用循环与多轮推理内容回传。

### F10. 模型发现模拟

Fake LLM Server 能模拟供应商的模型列表查询端点，返回模型列表；可注入认证失败、超时、服务端错误、未知模型，用于验证 CloseClaw 的模型发现、过滤未知模型、以及失败时回退到内置知识库的逻辑。

### F11. 管理面模拟

Fake LLM Server 能模拟供应商的管理查询端点——如 DeepSeek 的账户余额查询、GLM 的套餐用量配额查询——用于验证 CloseClaw 的余额与配额展示。

## 非功能需求

### 性能

- Fake LLM Server 对大量测试场景的响应速度不受场景数量增长影响

### 可用性

- 场景定义简洁、易编写、可复用，测试者无需了解真实模型或协议底层实现
- 无外部依赖：不依赖真实模型、算力、外部网络

### 可靠性

- 场景间相互隔离，一个场景注入的错误或延迟不污染后续场景
- 多个并发会话互不干扰，可模拟真实的多会话并发

### 安全性

- 仅监听本地回环地址，不对公网暴露
- 不进入发布构建，不随产品分发

### 可观测性

- 记录每次请求命中的场景、返回的响应与用量、缓存命中与断开事件，便于测试失败时定位
